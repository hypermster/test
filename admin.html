GitHub 연결

저장하려면 연결이 필요해요
토큰은 어떻게 만드나요?
  1. GitHub 토큰 만들기 화면을 엽니다.
  2. 이름(예: 안내서 관리)과 만료일을 정합니다.
  3. Repository access에서 Only select repositories → 를 고릅니다.
  4. Permissions → Contents를 Read and write로 바꿉니다.
  5. Generate token을 누르고, 나온 토큰을 위 칸에 붙여 넣습니다.

토큰은 비밀번호와 같습니다. 다른 사람에게 보내거나 채팅에 붙여 넣지 마세요. 이 페이지는 토큰을 GitHub에만 보냅니다.
